# E-commerce Data Cleaning Portfolio Project

A demonstration of data cleaning with Python and Pandas.

## Files
- `messy_ecommerce_data.csv`: synthetic source data with intentional quality issues
- `cleaned_ecommerce_data.csv`: cleaned output
- `cleaning_summary.csv`: cleaning metrics
- `cleaning_results.png`: before/after chart
- `data_cleaning_portfolio.ipynb`: runnable notebook with explanations and code

## Run
Keep the files in one folder, open the notebook in Jupyter or Google Colab, and run cells from top to bottom.

**Data note:** All records are synthetic. No real customer data is included.
